IT Helpdesk Ticket Management System

Python • Streamlit • MySQL • SQL Analytics
Project Overview

The IT Helpdesk Ticket Management System is designed to solve operational bottlenecks within organizations by providing a centralized web portal where employees can log hardware, software, and network issues.

Key Technical Architectural Highlights
  • Role-Based Authentication: Separate portals for regular employees to create & track tickets, and support agents/admins to assign, prioritize, and resolve them.
  • SQL Analytical Engine: Crafted complex aggregation queries and window functions to compute metrics such as Mean Time to Resolution (MTTR), SLA compliance rates, department-wise ticket distribution, and recurring issue patterns.
  • Relational Integrity: Designed normalized schemas in MySQL with foreign key constraints, indexes on status and timestamp columns for fast query execution, and audit trail logs.
  • Streamlit Frontend: Responsive and reactive user interface built purely in Python, allowing rapid prototyping and immediate data synchronization.

Python 3.x Streamlit MySQL Server PyMySQL / Connector SQL Analytics & Aggregation
